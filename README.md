## 🧑‍💻 Featured Projects

### 🦷 [OralGatedPCNN](https://github.com/yiminwang-ai/OralGatedPCNN)
Channel-Gated Skip Module for dental point-cloud segmentation.  
Integrates CSMBlock into PointCNN to suppress feature redundancy.  
📄 *Under review at Biomedical Signal Processing and Control*

### 🔧 [PointCloudCompletion](https://github.com/yiminwang-ai/PointCloudCompletion)
PF-Net based framework for completing partially scanned dental crowns from intraoral scans.  
📄 *Published at International Dental Journal*

### 📋 [Multimodal-Dental-AI-Review](https://github.com/yiminwang-ai/Multimodal-Dental-AI-Review)
PRISMA 2020 systematic review on multimodal AI for oral lesion screening.
